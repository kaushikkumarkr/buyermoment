# Roadmap

## P0

- Dedicated Azure resource group and cost tags.
- Validated canonical schema and deterministic ContextFit baseline.
- Dataset directory contract and 100-case synthetic CCB-1 seed.
- Reproducible evaluation CLI with honest baseline reporting.

## P1

- Source-specific ConvApparel, ESCI, and WANDS ingestion with license/NOTICE handling.
- Reviewed CCB-1 v0.1 gold/validation/hidden-test splits.
- Business Analyzer uploads and tenant-scoped persistence.
- Retrieval/candidate generation backed by evidence, followed by deterministic matching.

## P2

- Experiment adapters and import/export validation for documented platform formats.
- Authenticated web app, storage uploads, and Postgres persistence.
- ChatGPT Ads adapter refinement after a real documented format is available.

## P3/P4

- Azure-direct multi-model batch augmentation after eligibility and cost checks.
- Benchmark disagreement analysis and larger augmentation runs.
- Google AI Max outcome ingestion and platform-neutral conversion economics.
