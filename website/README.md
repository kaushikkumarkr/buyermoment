# BuyerMoment marketing site

This directory contains the customer-facing BuyerMoment landing page. It is intentionally separate from the application under `apps/web` so the marketing site can evolve without changing the product demo.

## Local preview

From this directory, serve `index.html` with any static HTTP server, for example:

```bash
python -m http.server 4173
```

The primary CTA currently uses `hello@buyermoment.ai` as a temporary contact address. Replace it with the team's real inbox or booking URL before public outreach.

The first published version is hosted at https://buyermoment.yash3561.chatgpt.site.
