# B2B SaaS metrics

BuyerMoment reports funnel stages separately: impression, click, lead, MQL, SQL, opportunity, pipeline, Closed Won, and revenue. The client defines qualification rules. BuyerMoment records the rule version and source.

Use qualified CPL, SQL rate, opportunity rate, pipeline/spend, CAC, ROAS, and payback only when the corresponding fields and lag are available. Small samples are plumbing validation, not causal proof.
