# Foundation and service reproducibility

The default local path is Python 3.11, SQLite, JSONL/CSV fixtures, and deterministic retrieval/constraint logic. Run `make test`, `make lint`, `make eval`, and the service integration tests from a clean checkout. Azure model calls are optional and routed by logical roles; no benchmark requires a paid call.

Private evidence and campaign files stay outside Git. Large public data remains governed by the existing dataset manifests and rights registry.
